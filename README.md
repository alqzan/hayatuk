# حياتك

سوبر آب شخصي عربي، جوّال أولًا، يجمع اليوم والأهداف والمهام والتقويم والمكتبة والمفكرة والذكريات والورد والميزانية في تجربة واحدة مترابطة.

**الرابط المنشور الوحيد:** https://alqzan.github.io/hayatuk/

## النسخة الحالية

نموذج أولي تفاعلي يعمل مباشرة من المتصفح ويعرض:

- واجهة أبسط تستفيد من وضوح «مدار» في الترتيب فقط، بهوية مستقلة وشعار هندسي خاص بـ«حياتك» ولوحة دافئة عاجية وذهبية وزيتونية مع خط ثمانية العربي.
- وضع نهاري ووضع ليلي محفوظان على الجهاز.
- دخول تجريبي بسيط بالاسم والبريد الاختياري، بلا كلمة مرور أو خادم خارجي.
- بداية فارغة تمامًا بلا بيانات عرض أو اقتراحات أو محتوى جاهز.
- لوحة يوم هادئة لا تعرض إلا ما أضافه المستخدم بنفسه.
- أهداف ومهام قابلة للإكمال.
- تقويم وتذكيرات مترابطة.
- مكتبة للكتب والصوت والفيديو والدورات والأفلام مع تقدم.
- إضافة سريعة لمهمة أو تذكير أو ملاحظة أو مصروف أو ذكرى أو مادة.
- ورد قرآني وميزانية ومفكرة وذكريات.
- حفظ تغييرات النموذج محليًا على الجهاز.

لا تُحمّل النسخة الحالية أي مهام أو أهداف أو كتب أو مصروفات أو أفكار تجريبية مسبقًا؛ جميع الأقسام تبدأ فارغة.

الدخول الحالي محلي وتجريبي وليس حسابًا حقيقيًا. التكامل مع تقويم الجهاز والتنبيهات والمزامنة والتخزين الكبير جزء من مراحل التطبيق الإنتاجية، ولا تدّعي نسخة العرض أنها حصلت على هذه الصلاحيات.
